# Spec: Третья практика «Мягкий белый шум»

## Что сделано

- Добавлен третий локальный файл `public/audio/soft-white-noise.mp3`: 3600 секунд (60:00), моно, 48 кГц, 48 kbps, ~21,6 МБ.
- Источник — видео [(No Ads) 10 Hours of Soft White Noise | Black Screen for Sleep](https://youtu.be/Og40mpl8VNc) (Let's Find Out, 10:40:27). Из него взят непрерывный час 1:00:00–2:00:00 без коротких повторов.
- Граница часового файла сведена двухсекундным равномощным кроссфейдом; декодированный PCM не содержит пауз, а скачок на стыке не превышает обычный p99.9 разницы соседних сэмплов.
- В `src/scripts/practices.ts` добавлена третья запись: `soft-white-noise`, «Мягкий белый шум», «1 час», base-aware URL.
- Radio-группа в `MeditationPlayer.astro` строится из данных и автоматически показывает три варианта; тексты страницы и manifest обновлены на «три практики».
- Плеер не менялся: смена источника, сброс позиции, отсутствие автозапуска, отсечение устаревших `play()` и Media Session работают для третьего трека по существующему контракту.
- Все три MP3 входят в precache; `maximumFileSizeToCacheInBytes` остаётся 24 МиБ, суммарный precache — около 64 МБ.
- Добавлен unit-тест состава практик; E2E расширены третьим вариантом, длительностью, precache и offline-запуском.

## Ключевые решения

- Для белого шума взят длинный непрерывный фрагмент, а не повтор короткой петли: так внутри часа нет склеек и повторяющегося рисунка.
- Формат и параметры совпадают с остальными практиками: MP3, 48 кГц, 48 kbps mono, час. Это упрощает плеер, precache и проверку.
- Двухсекундный кроссфейд на границе файла убирает щелчок при `loop`; он не слышен на стационарном шуме.
- Ограничение «ровно две практики» снято новым RFC только для третьей записи; дальнейшее расширение потребует отдельного RFC.
- UI остаётся одним экраном с одной основной кнопкой; третий вариант доступен касанием, клавиатурой и screen reader.

## Отклонения от RFC

- Источник скачан как полный Opus/WebM (549 МБ) и обработан локально: прямой доступ к диапазонам YouTube отдавал 403 для части клиентов. В репозиторий исходник не добавлен.
- Итоговая длительность ровно 3600 секунд, а не «около часа»; подпись в UI — «1 час».

## Известные ограничения / дальнейшие шаги

- Права на фрагмент видео и атрибуция канала не подтверждены; файл остаётся техническим placeholder-ом.
- Качество 48 kbps mono на реальных наушниках и устройствах не проверено.
- Реальные iOS/Safari и Android/Chrome не проверены: standalone offline, пятиминутный фон после сворачивания и блокировки, Media Session и обновление service worker остаются обязательными перед релизом.
- RFC остаётся в `docs/rfc/third-audio-track.md` со статусом `delivery`, пока открыты перечисленные критерии.
